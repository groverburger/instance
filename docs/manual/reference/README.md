# Function reference

Every built-in function, variable and constant of GML, grouped by topic. Each group page starts with a list of its sections; inside a section, functions and variables each have their own heading, and constants are listed in a table at the end of the section.

To find a name quickly, use the [A–Z index](index.md), or type it into the search box of the help window. In the code editor, put the text cursor on a name and press **F1** to open its entry.

## Groups

- [Computing](computing.md): functions for numbers, strings, dates and times, script arguments and the special instance references.
- [Game play](game-play.md): moving instances around, paths, motion planning, collisions, creating and destroying instances, timing, rooms, score, and generating events.
- [User interaction](user-interaction.md): reading the keyboard, the mouse and joysticks.
- [Game graphics](game-graphics.md): drawing sprites, backgrounds, shapes and text, blending, surfaces, tiles, the display, the game window and views.
- [Sound and music](sound-and-music.md): playing sounds and music, sound effects, 3D sound and CD audio.
- [Splash screens, messages and highscores](splash-and-messages.md): showing splash screens and information, asking the player questions, and keeping a highscore list.
- [Resources](resources.md): reading the properties of the game's resources, and creating, changing and deleting resources while the game runs.
- [Files, registry, INI files and programs](files-and-system.md): reading and writing files, the registry and INI files, running other programs, and information about the device.
- [Data structures](data-structures.md): stacks, queues, lists, maps, priority queues and grids.
- [Particles](particles.md): simple effects, and particle systems with types, emitters, attractors, destroyers, deflectors and changers.
- [Multiplayer](multiplayer.md): connections, sessions, players, shared data and messages for multiplayer games.
- [DLLs](dlls.md): calling functions in external DLLs.
- [3D graphics](3d-graphics.md): 3D mode, drawing primitives and shapes, projections, transformations, fog, lighting and models.
- [All functions, variables and constants (A–Z)](index.md)
