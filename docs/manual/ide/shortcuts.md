# Keyboard shortcuts

On macOS, use Cmd where this page says Ctrl.

## Everywhere in the IDE

| Keys | Action |
|---|---|
| Ctrl+N | New project |
| Ctrl+O | Open a project |
| Ctrl+S | Save the project |
| F5 | Run the game |
| F6 | Run the game in debug mode |

## Forms

| Keys | Action |
|---|---|
| Enter | OK: apply the changes and close the form (when no text field has the focus) |
| Escape | Close the form; asks first if there are unsaved changes |

## Resource tree

| Keys / mouse | Action |
|---|---|
| Double-click | Open the resource (or open/close a group) |
| F2 | Rename the selected item |
| Enter / Escape | Accept / cancel a rename |
| Right-click | Menu of commands for the item |
| Drag | Move the item, or drop it on a group to move it inside |

## Action lists (objects and time lines)

These work while the action list has the focus (click in it first).

| Keys / mouse | Action |
|---|---|
| Up, Down | Select the previous or next action |
| Delete | Delete the selected action |
| Ctrl+C, Ctrl+X, Ctrl+V | Copy, cut and paste actions (also between forms) |
| Double-click | Edit the action's settings |
| Drag | Move the action |

## Code editor

| Keys | Action |
|---|---|
| Ctrl+F | Open find and replace |
| Enter (in the Find field) | Find the next match |
| Ctrl+Z, Ctrl+Shift+Z | Undo, redo |
| Ctrl+A | Select all |
| Ctrl+C, Ctrl+X, Ctrl+V | Copy, cut, paste |
| Tab | Insert a tab |

## Room editor

| Keys / mouse | Action |
|---|---|
| Left click | Add an instance (or tile) |
| Alt + click/drag | Place without snapping to the grid |
| Shift + drag | Add many instances (or tiles), one per grid cell |
| Ctrl + drag | Move an instance (or tile) |
| Right-click | Instance menu (on the tiles tab: delete the tile) |
| Shift + right-click | Delete all instances at the position |
| Ctrl + right-click | Delete the instance under the mouse |
| Space + drag, middle-drag | Scroll the room |
| Mouse wheel | Zoom |

## Path editor

| Keys / mouse | Action |
|---|---|
| Click | Add a point |
| Drag a point | Move it |
| Shift + click a point | Insert a point |
| Right-click a point | Delete it |
| Alt | Don't snap to the grid |
| Middle-drag | Scroll |
| Mouse wheel | Zoom |

## Image editor

| Keys / mouse | Action |
|---|---|
| Left / right mouse button | Draw with the left / right colour |
| Ctrl+Z | Undo |
| Ctrl+Y, Ctrl+Shift+Z | Redo |
| Ctrl+A | Select all |
| Ctrl+C, Ctrl+X, Ctrl+V | Copy, cut, paste the selection |
| Delete | Delete the selection |
| Escape | End the selection (or cancel the text being placed) |
| Enter | Apply the text being placed |
| Shift (while drawing) | Straight lines with the Pencil; 0/45/90° lines; squares and circles |
| Ctrl (Pencil) | Pick the colour under the mouse |
| Mouse wheel | Zoom |
| Middle-drag | Scroll |

## Debug Information window

| Keys | Action |
|---|---|
| Delete | Delete the selected watch expression |
| Enter (in the Execute code field) | Run the code |

## In the game

These keys are handled by every game, unless they are switched off on the
[Other tab](game-settings.md#other) of the game settings:

| Key | Action |
|---|---|
| Esc | End the game |
| F1 | Show the game information |
| F4 | Switch between window and full screen |
| F5, F6 | Save the game, load the game |
| F9 | Save a screenshot |
