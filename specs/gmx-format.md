# GameMaker: Studio 1.x projects (`.gmx`, `.gmz`) and their GM 8.1 mapping

Clean-room notes. Everything here was derived from **project data files** only: the
user's own Studio 1.x projects (14 `*.project.gmx` folders) and one `.gmz` export
(`SpelunkyClassic-YoYo.gmz`, ~4000 files). No YoYo executable was run, disassembled or
debugged. Where a feature did not occur in the corpus the layout is marked **[I]**
(inferred by analogy with neighbouring files) — implementations must tolerate absence.
**[V]** = present in the corpus.

Implementation: `crates/gm-gmx` (`load_gmx(path) -> (gm_format::Project, Vec<Warning>)`,
CLI `gmx2gm81`). Target model: `crates/gm-format` / `specs/file-formats.md`.

## 1. Containers

* **Folder project [V]**: a directory `Name.gmx/` holding `Name.project.gmx` plus one
  sub-folder per resource kind. A folder may contain further nested projects (one
  corpus project had `pokemon3.gmx/` inside); the shallowest `*.project.gmx` wins.
* **`.gmz` [V]**: an archive of such a folder. Despite the name it is not always a
  zip: the corpus file starts with `37 7A BC AF 27 1C` (7-Zip). Detect by magic:
  `PK` → zip, `7z\xBC\xAF\x27\x1C` → 7z. Entry names may use `\` separators.
* Paths inside documents use `\` and are matched case-insensitively (Windows).
* Text files are UTF-8 (sometimes with BOM); fall back to Windows-1252.
* Every XML document starts with a `<!-- ... generated by GameMaker ... -->` comment.
* Booleans are written as `-1`/`0` (most files) or `True`/`False`/`true`/`false`
  (config files). Treat any non-zero number or `true` (any case) as true.
* "No resource" is written `<undefined>` (escaped `&lt;undefined&gt;`) or empty.

## 2. `Name.project.gmx` [V]

Root `<assets>`. Children (all optional, in this order in the corpus):

| Element | Content | GM 8.1 |
|---|---|---|
| `<Configs name="configs"><Config>Configs\Default</Config>` | configuration documents | settings, §9 |
| `<datafiles number="N" name="datafiles">` | included files, nested `<datafiles name=…>` folders, `<datafile>` leaves [I] | included files §10 |
| `<NewExtensions>` `<extension index="0">extensions\Name</extension>` | extensions | §11 |
| `<sounds name="sound">` | `<sound>sound\x</sound>` | sounds |
| `<sprites name="sprites">` | `<sprite>sprites\x</sprite>` | sprites |
| `<backgrounds name="background">` | `<background>background\x</background>` | backgrounds |
| `<paths name="paths">` | `<path>paths\x</path>` [I] | paths |
| `<scripts name="scripts">` | `<script>scripts\x.gml</script>` | scripts |
| `<shaders name="shaders">` | `<shader type="GLSLES">shaders\x.shader</shader>` | dropped |
| `<fonts name="fonts">` | `<font>fonts\x</font>` | fonts |
| `<timelines name="timelines">` | `<timeline>timelines\x</timeline>` [I] | time lines |
| `<objects name="objects">` | `<object>objects\x</object>` | objects |
| `<rooms name="rooms">` | `<room>rooms\x</room>` | rooms |
| `<constants number="N">` | `<constant name="NAME">expr</constant>` | user constants |
| `<help><rtf>help.rtf</rtf></help>` | RTF file | game information |
| `<TutorialState>` | IDE state | ignored |

**Resource tree.** Inside each section, an element with the *plural* tag and a `name`
attribute is a user group (folders nest arbitrarily); a *singular* element is a
resource whose text is the path without extension. The resource name is the last path
component (`.gml` / `.shader` stripped). Resource indices are assigned in document
order (depth-first), which is also the order of the 8.1 resource lists; the converter
rebuilds the 8.1 tree with the same groups. There is no "deleted slot" concept.

Resource file per leaf: `<path>.sprite.gmx`, `.sound.gmx`, `.background.gmx`,
`.path.gmx`, `.font.gmx`, `.timeline.gmx`, `.object.gmx`, `.room.gmx`; scripts and
shaders are the path itself. All relative paths inside a resource document are
relative to the folder of that document.

## 3. Sprites — `<sprite>` [V]

| Element | Meaning | GM 8.1 sprite |
|---|---|---|
| `type` | 0 bitmap, 1 SWF vector, 2 Spine skeleton | only 0 supported (others: empty + warning) |
| `xorig`, `yorigin` | origin | `origin_x/y` |
| `colkind` | 0 precise, 1 rectangle, 2 ellipse, 3 diamond | `collision_shape` (same numbering) |
| `coltolerance` | alpha tolerance 0..255 | `alpha_tolerance` |
| `sepmasks` | separate mask per frame | `separate_collision_masks` |
| `bboxmode` | 0 automatic, 1 full image, 2 manual | `bbox_mode` |
| `bbox_left/right/top/bottom` | bounding box (inclusive) | same |
| `HTile`, `VTile`, `For3D`, `TextureGroups/TextureGroupN` | texture-page hints | ignored |
| `width`, `height` | frame size | frames are cropped/padded to it |
| `frames/frame index="i"` | `images\name_i.png` | frames (sorted by `index`) |

Frames are 32-bit RGBA PNGs (any PNG colour type must be accepted). Unlike GM 8.1,
Studio stores the bounding box explicitly; it is copied as is (8.1 recomputes it for
automatic mode).

## 4. Backgrounds — `<background>` [V]

`istileset`, `tilewidth`, `tileheight`, `tilexoff`, `tileyoff`, `tilehsep`, `tilevsep`
map 1:1 to the 8.1 tile-set fields; `width`/`height` give the image size and
`data` the PNG (`images\name.png`). `HTile`/`VTile`/`For3D`/`TextureGroups` ignored.

## 5. Sounds — `<sound>` [V]

| Element | Meaning | GM 8.1 sound |
|---|---|---|
| `kind` | 0 normal, 1 background music, 2 3D, 3 "multimedia player" (mp3) | `kind` (same numbering) |
| `extension` | `.wav`, `.mp3`, `.ogg` | `file_type` |
| `origname` | original path | – |
| `effects` | DirectX effect bits (legacy audio) | `effects` |
| `volume/volume` | 0..1 (one value per config) | `volume` |
| `pan` | −1..1 | `pan` |
| `bitRates`, `sampleRates`, `types`, `bitDepths`, `compressed`, `streamed`, `uncompressOnLoad` | new-audio export settings | ignored |
| `preload` | | `preload` |
| `data` | file name inside `sound\audio\` | `data` (raw file bytes), `file_name` |
| `audioGroup` | audio group index | dropped (warning when ≠ 0) |

## 6. Fonts — `<font>` [V]

`name` (Windows font family; a leading `@` selects the vertical CJK variant and is
stripped), `size`, `bold`, `italic`, `charset`, `aa` (0–3), `renderhq`, `includeTTF`
+ `TTFName`, `texgroups`, `ranges/rangeN` = `first,last` (several ranges possible),
and **`glyphs/glyph character x y w h shift offset`** describing a texture
`fonts\name.png` that Studio pre-renders.

GM 8.1 fonts are rendered from the installed system font at load time, so the 8.1
font gets name/size/style/charset/antialias and the range `min(first)..max(last)`
(clipped to 255). Because the font may not be installed (custom TTFs are common), the
converter also turns the pre-rendered glyphs into a **sprite font**: one frame per
character of the range, glyph pixels copied white-with-alpha at x = `offset`, frames
top-aligned (glyph rectangles are cropped at the bottom only), and two alpha-1 marker
pixels at columns 0 and `shift−1` so that a proportional sprite font advances by
exactly `shift`. At game start the first room's creation code calls
`font_replace_sprite(font, sprite, first, true, 0)`, keeping the font's resource id.
(`gmx2gm81 --system-fonts` keeps system rendering.)

## 7. Objects — `<object>` [V]

| Element | GM 8.1 object |
|---|---|
| `spriteName`, `maskName` | `sprite`, `mask_sprite` (by name) |
| `solid`, `visible`, `depth`, `persistent` | same |
| `parentName` | `parent` (`<undefined>` and, in older files, `self` mean none) |
| `PhysicsObject*`, `PhysicsShapePoints` | dropped (warning when `PhysicsObject` is set) |
| `events/event eventtype="T" enumb="N"` | event `(T, N)` |
| `event eventtype="4" ename="obj"` | collision event, number = index of `obj` |

Event types and numbers are the GM 8.1 ones, with Studio additions:

| Studio event | (type, number) | Conversion |
|---|---|---|
| Draw GUI, Draw GUI Begin/End | (8, 64), (8, 74), (8, 75) | GUI emulation, §7.1 |
| Draw Begin / Pre-Draw | (8, 72), (8, 76) | prepended to the Draw event, §7.2 |
| Draw End | (8, 73) | appended to the Draw event, §7.2 |
| Post-Draw | (8, 77) | treated like GUI |
| Window resize | (8, 65) | dropped |
| Async events (image loaded, HTTP, dialog, IAP, cloud, networking, Steam, social, push notification, save/load, audio recording/playback, system) | (7, 60…75) | dropped with warning |
| user events, outside/boundary view | (7, 10…25), (7, 40…57) | identical to 8.1 |

### 7.1 Draw GUI emulation

GM 8.1 draws only per view, in room coordinates. The converter moves every GUI event
to a free user event `G` (searched from 15 downwards, avoiding user events used by any
object or referenced as `ev_userN`) and adds an object `__gmx_gui_controller` (depth
−31000, so it draws last but stays inside the ±32000 z range of orthographic
projections), placed in every room. Its Draw event, on the last visible view only (or
always when views are disabled), sets
`d3d_set_projection_ortho(0, 0, display_get_gui_width(), display_get_gui_height(), 0)`
and runs `with (obj) if (visible) event_perform(ev_other, ev_userG)` for each object
with a GUI event that has no ancestor with one (sorted by depth, deepest first).
GUI size: `display_set_gui_size` (compat script) else view port 0, else the room.
Studio leaves `view_current` at the last view index (7) while GUI events run (the
Spelunky port tests `view_current == 7` in its HUD); reads of `view_current` are
therefore rewritten to `__gmx_view_current()`, which returns 7 during GUI drawing
(0 without views).

### 7.2 Draw Begin / Draw End

Merged into the object's Draw event: Begin actions, then the object's own Draw actions
(or `event_inherited()` if an ancestor has a Draw event, or a default
`draw_sprite_ext(sprite_index, image_index, x, y, …)` otherwise — adding a Draw event
would otherwise suppress the default drawing), then End actions. Cross-instance
ordering (all Begins before all Draws) is lost.

### 7.3 Actions — `<action>` [V]

Same fields as a GM 8.1 action record, by name: `libid`, `id`, `kind`,
`userelative`, `isquestion`, `useapplyto`, `exetype`, `functionname`, `codestring`,
`whoName` (`self`, `other` or an object name → −1, −2, index), `relative`, `isnot`,
`arguments/argument` with `kind` and one value element. The value element's tag names
the resource kind: `string` (expressions, strings, colours, menus, booleans) or
`sprite`, `sound`, `background`, `path`, `script`, `object`, `room`, `font`,
`timeline` holding a **resource name** (converted to the index). Argument lists are
padded to 8 entries. Library/action ids are the GM 8.1 ones (`1/603` execute code,
`1/604` call inherited, `1/601` execute script, `1/611` set variable, …): all 29
distinct (library, action) pairs in the corpus exist in the 8.1 libraries
(specs/actions.json) with the same function names [V].

## 8. Rooms — `<room>` [V]

| Element / attribute | GM 8.1 room |
|---|---|
| `caption`, `width`, `height`, `hsnap`, `vsnap`, `isometric`, `speed`, `persistent` | same (`hsnap`→`snap_x`, `vsnap`→`snap_y`) |
| `colour`, `showcolour` | `background_color`, `draw_background_color` |
| `code` | room creation code |
| `enableViews` | `views_enabled` |
| `clearViewBackground`, `clearDisplayBuffer` | ignored |
| `makerSettings/*` (`isSet w h showGrid showObjects showTiles showBackgrounds showForegrounds showViews deleteUnderlyingObj deleteUnderlyingTiles page xoffset yoffset`) | room-editor state |
| `backgrounds/background visible foreground name x y htiled vtiled hspeed vspeed stretch` | 8 layers |
| `views/view visible objName xview yview wview hview xport yport wport hport hborder vborder hspeed vspeed` | 8 views |
| `instances/instance objName x y name locked code scaleX scaleY colour rotation` | instances |
| `tiles/tile bgName x y w h xo yo id name depth locked colour scaleX scaleY` | tiles |
| `PhysicsWorld*` | dropped (warning when enabled) |

* Instances have a **name** (`inst_XXXXXXXX`) instead of a numeric id; Studio code can
  refer to it as a constant. The converter numbers instances from 100001 in room order
  and adds a user constant for every instance name used in code.
* Per-instance `scaleX`, `scaleY`, `rotation` and `colour` (unsigned ARGB:
  alpha << 24 | BGR; 4294967295 = opaque white) do not exist in 8.1; they become
  `image_xscale/image_yscale/image_angle/image_blend/image_alpha` assignments at the
  start of the instance creation code (they precede Create in Studio as well).
* Tile `scaleX/scaleY/colour` become `tile_set_scale/tile_set_blend/tile_set_alpha`
  calls at the start of the room creation code. Tile depths are kept (Studio's tile
  "layers" are just depths).
* Rooms with an empty caption get the game name (Studio shows the display name; GM 8.1
  would show "Score: 0"); `show_score = false` runs in the first room's creation code.

**Creation order.** GM 8.1 runs an instance's creation code *before* its Create event
(runtime.md §3.2); Studio runs the Create event first, so creation code overrides
defaults set in Create. For every object that has instances with creation code (and
its ancestors) the converter moves the Create actions to a free user event `U` and
replaces Create with a stub; the creation code becomes
`<transform>; event_perform(ev_other, ev_userU); __gmx_cc_done = true; <code>` and the
stub skips once when `__gmx_cc_done` is set. `event_inherited()` inside the moved
actions resolves to the parent's user event `U`, i.e. the parent's (moved or stub)
Create. (`--gm8-create-order` disables this.)

## 9. Configuration — `Configs\Default.config.gmx` [V]

`<Config><Options>` holds hundreds of `option_*` elements, most for other platforms
(`option_android_*`, `option_ios_*`, `option_html5_*`, …; ignored). Mapped:

| Option | GM 8.1 setting |
|---|---|
| `fullscreen`, `interpolate`, `noborder`, `showcursor`, `scale`, `sizeable`, `stayontop` | start fullscreen, interpolate, no border, cursor, scaling, resizable, on top |
| `windowcolor` (`clBlack`, Delphi colour names, `#RRGGBB` or number) | colour outside room |
| `changeresolution`, `colordepth`, `resolution`, `frequency`, `sync_vertex` | display settings |
| `nobuttons`, `noscreensaver` | window buttons, screensaver |
| `screenkey` F4, `helpkey` F1, `quitkey` Esc, `savekey` F5/F6, `screenshotkey` F9, `closeesc` | key options |
| `priority`, `freeze` | process priority, freeze on focus loss |
| `showprogress` (0/1/2), `backimage`, `frontimage`, `loadimage`, `hasloadimage`, `loadtransparent`, `loadalpha`, `scaleprogress` | loading bar (custom images not converted) |
| `displayerrors`, `writeerrors`, `aborterrors` | error options |
| `variableerrors`, `argumenterrors` | uninitialised-variable flags (see below) |
| `author`, `version`, `information`, `version_major/minor/release/build`, `version_company/product/copyright/description` | information |
| `gameid`, `gameguid` | game id, GUID |
| `windows_game_icon` (path to `.ico`) | icon |
| `display_name` | game name (window caption fallback) |
| `shortcircuit` | GML translation, §12 |
| `audioGroupCount`, `textureGroup*`, `use_new_audio` | ignored |

`<ConfigConstants><constants>` add more user constants. The converter defaults
"treat uninitialised variables as 0" to **on** (`--uninit-error` / `--uninit-studio`
to change): Studio code relies on short-circuit evaluation and lenient reads that
GM 8.1 would turn into runtime errors.

## 10. Data files ("included files") [I]

`<datafile>` children: `name`, `exists`, `size`, `exportAction` (0 none, 1 temp,
2 game folder, 3 custom), `exportDir`, `overwrite`, `freeData`, `removeEnd`, `store`,
`filename`; the file lives at `datafiles\<folder>\<filename>`. Studio makes data files
readable from the working directory, so they are exported to the game folder (8.1
export kind 2) by default. The corpus only had empty `<datafiles number="N"/>` stubs.

## 11. Extensions [V, partially I]

`extensions\Name.extension.gmx` (`<extension>`: `name`, `version`, `packageID`,
`IncludedResources/Resource`, `files/file` …) plus a folder `extensions\Name\`.
"Asset package" extensions (corpus) only list `IncludedResources`; those resources were
already imported into the project's own sections, so nothing is needed. For `files`
[I]: a GML file (`kind` 2 or `.gml`) is split at `#define` into scripts; native files
(DLL, JS, …) are reported with their function names (unsupported).

## 12. GML differences (Studio 1.x → GM 8.1)

Studio 1.x GML is a superset of 8.1 GML (specs/gml-language.md). The converter parses
every code piece (scripts, code actions, expression arguments, room and instance
creation code) into an AST and re-emits only the nodes that need it; everything else is
copied byte for byte (comments and layout survive).

| Studio construct | GM 8.1 output |
|---|---|
| `x++`, `--x` as statements | `x += 1`, `x -= 1` |
| `++`/`--` inside expressions | hoisted before the statement: `var __gmx_tN; __gmx_tN = x; x += 1;` (postfix value) or `x += 1;` (prefix) |
| `c ? a : b` | `var __gmx_tN; if (c) { __gmx_tN = a; } else { __gmx_tN = b; }` hoisted |
| `l[| i]`, `m[? k]`, `g[# x, y]`, `a[@ i]` (reads) | `ds_list_find_value(l, i)`, `ds_map_find_value(m, k)`, `ds_grid_get(g, x, y)`, `a[i]` |
| accessor assignment `=` / `op=` / `++` | `ds_list_replace`, compat `__gmx_ds_map_set` (add or replace), `ds_grid_set` / `ds_grid_add` / `ds_grid_multiply` |
| `0xFF` | `$FF` |
| `var a = 1, b;` | `var a, b; a = 1` |
| `for (var i = 0; …)` | `{ var i; for (i = 0; …) … }` |
| `return;` | `exit` |
| `%=`, `<<=`, `>>=` | `a = a mod (b)` etc. |
| `enum E { A, B = 5 }` / `E.A` | declaration removed, members inlined as numbers |
| `#define name` (script files, GML extensions) | split into separate scripts |
| `#macro NAME value` (GMS2), `#region` | user constant; region lines commented out |
| strings with `\"`, `\n` (GMS2 only, `--string-escapes`) | re-quoted / `#`; **GMS1 has no escapes**, so this is off by default |
| short-circuit `a && b`, `a || b` | 8.1 evaluates both operands. When the right operand reads another instance's variable (`obj.x`, `inst.x`, `f().x`), it is hoisted into nested `if`s (`option_shortcircuit`, default on). |

Statements needing hoisting are wrapped in `{ … }`; `while`/`do…until`/`for`
conditions that need hoisting become `while (true) { …; if (!(cond)) break; … }`.
Operator precedence is taken to be the 8.1 one (the Studio 1.x manual lists the same
groups); parenthesisation in the source is preserved.

**Name resolution.** British spellings (`draw_text_colour`, `make_colour_rgb`, …) are
renamed when the `color` spelling is an 8.1 function. Unknown identifiers that are
never assigned anywhere in the project and are not 8.1 built-ins, resources, constants
or instance names are reported per project.

## 13. Compatibility layer

`crates/gm-gmx/src/compat.rs` holds GML scripts injected (only when used and only when
8.1 lacks the name — checked against `specs/builtins.json`):

* maths/geometry: `point_in_rectangle`, `point_in_circle`, `point_in_triangle`,
  `rectangle_in_rectangle`, `angle_difference`, `dot_product(_3d)`, `int64`, `get_timer`;
  type checks `is_undefined`, `is_array`, … (always false; 8.1 has no such values);
  `array_length_1d/2d`, `array_height_2d` return 0 (8.1 arrays are not values — reported).
* strings: `string_byte_at`, `string_byte_length`, `string_hash_to_newline`, `ansi_char`.
* data structures: `ds_map_set`, `ds_list_set`, `ds_exists`, `__gmx_ds_map_set`.
* instances: `variable_instance_get/set/exists`, `asset_get_index` (via `execute_string`).
* audio: `audio_play_sound(snd, prio, loop)` → `sound_play`/`sound_loop`, returning the
  sound index so `audio_stop_sound`/`audio_is_playing` work; gains → `sound_volume` /
  `sound_fade` / `sound_global_volume`; groups, emitters, listeners, pitch → no-ops.
* gamepads: `gamepad_*` → `joystick_*` (device *n* = joystick *n+1*; `gp_face1..4`,
  shoulders, start/select → buttons 1..12, d-pad → axes/POV); `gamepad_button_check_pressed`
  keeps the previous state in a global.
* display/window/device: `display_set_gui_size`, `display_get_gui_width/height`,
  `device_mouse_*`, `window_has_focus`, `os_get_language`, … ; `surface_resize`,
  `application_surface_*`, `shader_*`, `texture_set_stage` → no-ops.
* Studio semantics of 8.1 functions: `file_text_open_read` / `file_bin_open` return −1
  for a missing file (8.1 raises an error); calls are redirected to `__gmx_…` wrappers.
* constants: `gp_*`, `os_*` platforms, `browser_*`, `ev_gui`/`ev_draw_begin`/…,
  `audio_falloff_*`, `ds_type_*`, `buffer_*`, `pointer_null`, `undefined` (= 0).
* Studio-only variables are replaced on read: `application_surface` → −1,
  `delta_time` → `1000000 / room_speed`, `browser_width/height` →
  `window_get_width/height()`, `os_browser` → −1, `fps_real` → `fps`, `async_load` → −1.

Every other unknown function becomes a stub script returning 0 and is listed in the
warnings ("unknown functions").

## 14. Dropped / unsupported (reported as warnings)

Shaders (resource dropped; `shader_*` calls become no-ops and shader names become
constants), physics (objects and room worlds), audio groups, texture groups, async
events, window-resize event, SWF/Spine sprites, embedded TTF files (the glyph texture is
used instead), native extension files, custom loading-bar images, per-platform options.
