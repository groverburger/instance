# Black-box test manifest

Generated by `cargo run -p instance-blackbox -- manifest`; do not edit by hand.

The generator (`crates/instance-blackbox`) writes small GM 8.1 projects that log observations
as `key=value` lines (on screen, to `results_<name>.txt`, and to the clipboard). The user
runs them in the real GameMaker 8.1 (Lite); `instance-blackbox run-ours` runs them in
instance-runner; `instance-blackbox compare <ours> <gm>` lists the differences together with the
question ids below (OPEN_QUESTIONS.md ids such as RT-08, GML-4, G-26; spec sections).

Conventions: strings are logged in double quotes, reals with up to 10 decimals
(`string_format` with trailing zeros removed, so independent of `string()`).
Tests that may raise an error log `key` (`"<unset>"` if the statement did not
complete), `key.err` (`error_occurred`) and `key.msg` (`error_last`); a test whose
whole event was abandoned logs `key.aborted=1` on the next step. Display of errors
is switched off in the generated settings so no dialog interrupts the run.
Event-sequence keys (`ev.sNN`, `in.sNN`, `rm.sNN`, ...) hold space-separated tags
`<instance>.<event>` for the step that ended (s00 = everything before the first
Begin Step); long sequences continue in `key+1`, `key+2`. Event tags: CR create,
IC instance creation code, CC room creation code, DE destroy, A<n> alarm (value of
alarm[n] inside the event in brackets), BS/ST/ES begin/normal/end step, DR draw, CO
collision, OR outside room, IB intersect boundary, AE animation end, PE path end,
RS/RE room start/end, GS/GE game start/end, NML/NMH no more lives/health, U0 user 0,
TL<n> timeline moment, TRbs/TRst/TRes trigger (begin/step/end moment), KP/KB/KR key
press/held/release, k.BS = the clock instance (first in instance order).

## Not covered

- D3D-*, surfaces, particles, blend modes, data structures, multiplayer, DLLs: Pro-only
  in GM 8.1 (the test machine has Lite).
- SND-1..5, SND-7 need audio measurement; JOY-* need a joystick; IDE-* and FF-* are
  about the editor and file contents (observe the IDE / save files instead). The
  Errors tab of bb_lang / bb_args0 (README step) answers FF-18 / IDE-12.
- Mouse events (RT-14) need real mouse input.
